# ModelDistl

ModelDistl is a local training project for a 4.02-billion-parameter coding, math, reasoning, and general-assistance model. GPT-6.2 Astra supplies demonstrations for supervised fine-tuning. The student starts from Qwen3-4B-Instruct-2507, with 4-bit adapter training on Apple silicon and GGUF inference through llama.cpp.

The source model is [Qwen3-4B-Instruct-2507](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507/tree/cdbee75f17c01a7cc42f958dc650907174af0554), licensed under Apache 2.0.
